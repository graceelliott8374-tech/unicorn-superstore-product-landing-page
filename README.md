# Unicorn Superstore Product Landing Page

This project was completed during the PERSEVERE Coding Bootcamp while I was incarcerated.

The assignment was to design a responsive product landing page. I created a fictional **Unicorn Superstore**, combining HTML, CSS, multimedia, and creative branding into a fully themed website.

The project is preserved in its original form to document my early growth as a front-end developer.
